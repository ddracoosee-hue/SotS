# Chapter Briefs

<!--
One brief per chapter lives here: `ch01_brief.md`, `ch02_brief.md`, …
(copied by `sots init` as an empty folder with this README).
-->

Each brief covers the ChapterBrief fields (blueprint 03 §8):

- **Chapter ID** — e.g. `ch01` (matches the file name).
- **Title** — the chapter's working title.
- **Purpose** — what this chapter exists to do in the book.
- **Key Messages** — the M-ids from `messages.yaml` this chapter serves.
- **Planned Stories** — personal stories you intend to tell here.
- **Planned References** — facts, cases, or media you intend to use.
- **Reader Takeaway** — what the reader leaves this chapter with.

Write the brief in your own words below a `#` title line; keep the raw text —
it is preserved verbatim as `raw_brief` and only you can revise it.
